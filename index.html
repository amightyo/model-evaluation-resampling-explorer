Before We Evaluate: What Is a Train/Test Split?

A train/test split separates available observations into two roles. The model learns from one portion and is evaluated on observations it was not allowed to learn from.

Training set

Test set
Held-out observations used to estimate performance on unseen data.
Random state / seed
Makes a random assignment reproducible. It is not a knob for searching for a favorable score.

5. From Repeated Holdouts to Cross-Validation

Repeated arbitrary holdouts helped us see instability. Cross-validation gives us a systematic resampling design: in 5-fold cross-validation, each fold serves once as validation data while the remaining folds are used for training.

6. Cross-Validation Is Not a Universal Recipe

SituationEvaluation question
Imbalanced classesShould folds preserve class proportions, and is accuracy appropriate?
Time-ordered dataWould random splitting allow the model to learn from the future?
Repeated observations / groupsCould related observations appear in both training and validation data?
Preprocessing or feature selectionWas each step learned only from the training portion of each resample?
Model tuningAre the same observations being used both to choose the model and claim final performance?
Leakage warning: Resampling cannot rescue an evaluation if validation or test information has already influenced model development.
